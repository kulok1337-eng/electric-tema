# Что изменилось

- `/start` для новых пользователей показывает кнопки «Я клиент — оставить заявку» и «Я мастер».
- Клиент оставляет заявку без регистрации и одобрения; отмена — кнопка «Отменить заявку» или /cancel.
- Админам приходит карточка с пометкой «От клиента» / «От мастера».
- Заявки клиентов не начисляют партнёрскую комиссию.
- /client запускает форму клиента напрямую.
- БД мигрируется автоматически с копией bot_database.db.bak-...
- Токен: переменная BOT_TOKEN, а если её нет — значение из config.py.
